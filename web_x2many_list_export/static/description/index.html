X2Many Excel Export for Odoo 19

Add an Export Excel button to one2many and many2many list fields

X2Many Excel Export lets developers enable Excel export directly inside embedded list views on Odoo forms. Add export_xlsx="1" to the nested <list> tag and users can download the list records as an XLSX file.

Simple XML Switch

Enable export per list with export_xlsx="1". No Python code is needed in your business module.

X2Many Ready

Works with embedded one2many and many2many list views inside Odoo form views.

Native XLSX Export

Uses Odoo's standard XLSX export endpoint, so exported files keep the familiar Odoo Excel format.

Usage

<field name="line_ids">
    <list string="Lines" editable="bottom" export_xlsx="1">
        <field name="name"/>
        <field name="date"/>
        <field name="amount"/>
    </list>
</field>

Feature Summary

  • Adds an Export Excel button to x2many list fields.
  • Enabled only when the nested list has export_xlsx="1".
  • Supports one2many and many2many list views.
  • Exports visible scalar columns from the list view.
  • Skips hidden columns and unsupported relational columns.
  • Designed for Odoo 19 backend forms.

Installation

Copy the module to your addons path, update the apps list, then install X2Many Excel Export. Add export_xlsx="1" to the x2many list views where the export button should appear.
